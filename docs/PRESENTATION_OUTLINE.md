# Kuchbrtna — скелет презентации

1. Проблема: обучение на одной бесплатной T4 ограничено памятью и временем.
2. Операции: CE/head, NF4, RMSNorm, RoPE; SwiGLU обозначить примером организаторов.
3. Устройство кернелов: chunk logits → CE/entropy/argmax и gradient logits → matmul grad hidden в forward → сохранение scaled fp16 gradient → масштабирование в backward. RMSNorm/RoPE/NF4 описаны в IMPLEMENTATION.md.
4. Результаты:

| Метрика | Base Soup | Решение | Отношение |
|---|---|---|---|
| Полное время, с | 89,56 | 70,31 | 1,2738× ускорение |
| Пик GPU-памяти, MiB | 14 345 | 5 465 | 2,6249× меньше |
| Eval loss | 2,04966 | 2,04966 | практически без изменения |

5. Корректность: 10/10 checks, 79 тестов Soup; собственные кернелы 9,3% (минимум 5%).
6. Ограничения: один запуск каждой стороны, открытая выборка, seed=1; скрытая проверка впереди.
