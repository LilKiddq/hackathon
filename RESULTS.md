# Подтверждённые результаты Kaggle T4

| Метрика | Base Soup | Решение | Отношение |
|---|---|---|---|
| Полное время, с | 89,56 | 70,31 | 1,2738× ускорение |
| Пик GPU-памяти, MiB | 14 345 | 5 465 | 2,6249× меньше |
| Eval loss | 2,04966 | 2,04966 | практически без изменения |

Все 10 автоматических проверок пройдены. Собственные кернелы занимают 9,3% времени обучения с шага 3.
79 регрессионных тестов Soup пройдены. 39 тестов solution пройдены по выводу пользователя; их отдельный лог в архив не входит.

Источник: evidence/result.json и evidence/checks.json. SHA-256 result.json совпал со значением в checks.json.
Условия: одна Tesla T4, seed=1, 64 шага; по одному запуску базы и решения, открытая eval-выборка из 256 строк.
Это не итоговая проверка жюри на скрытых данных и не среднее двух повторов.

Запущенные собственные кернелы по check 3:
- lm_head_ce_kernel (solution/fused_ce.py)
- nf4_dequant_kernel (solution/nf4.py)
- rms_norm_bwd_kernel, rms_norm_fwd_kernel (solution/rmsnorm.py)
- rope_rotate_kernel (solution/rope.py)

add_rmsnorm_bwd_kernel и add_rmsnorm_fwd_kernel не запускались во всех solution runs; не заявляем их активным вкладом.
SwiGLU из примера организаторов не засчитывается как собственный.

Полученный Kuchbrtna-solution.zip сверен по алгоритму harness: SHA-256 относительных POSIX-путей и байтов файлов, без __pycache__. Совпадение точное.
Техническое описание актуальной реализации: docs/IMPLEMENTATION.md. Исходные .py включены без изменений.
